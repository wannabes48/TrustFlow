SmartFlow is a simple web application that provides an AI-driven alternative credit score for informal workers.<br>

The app allows users to input or paste mobile money transaction data (CSV or text format with Date, Amount, Type: IN/OUT).<br>

The system does the following:<br>

Parses the transaction data<br>
Calculates a Trust Score (0–100) based on:<br>
Total income<br>
Spending vs income balance<br>
Transaction consistency (frequency)<br>


Key features implemented:<br>
1. Transaction Parsing: Users can paste their mobile money transaction data in CSV format (Date, Amount, Type). The app uses papaparse to extract and structure this data.<br>
2. AI-Driven Analysis: The parsed data is summarized (total income, expenses, net balance, and monthly grouping) and sent to the Gemini AI model to evaluate income stability, spending patterns, and transaction consistency.<br>
3. Dashboard UI: A clean, responsive dashboard displays the results, including:<br>
4. A large, visual Trust Score (0–100).<br>
5. A Risk Level indicator (Low, Medium, High).<br>
6. A suggested Loan Eligibility amount.<br>
7. A Personalized Savings Recommendation generated by AI.<br>
8. Visual Analytics: A bar chart built with recharts visually compares monthly income versus expenses to help users understand their financial flow.<br>
